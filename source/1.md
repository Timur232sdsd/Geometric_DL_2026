По-русски:

**TDA-диагностика представлений sheaf neural networks на частично упорядоченных структурах**

## Главный исследовательский вопрос

> Как меняются топологические характеристики скрытых представлений Sheaf Neural Networks в процессе обучения на poset-структурах, и связаны ли эти изменения с качеством обобщения?

## Основные гипотезы

### Гипотеза 1

Во время обучения скрытые представления становятся более топологически стабильными:

- короткоживущие topological features исчезают;
- долгоживущие компоненты становятся более выраженными;
- total persistence и persistence entropy меняются монотонно или устойчиво.

### Гипотеза 2

SNN формирует более «структурные» представления, чем MLP и GCN, потому что sheaf-механизм учитывает локально-глобальные ограничения poset.

Ожидаемое наблюдение:

- у SNN выше accuracy на poset-задаче;
- у SNN более чёткая H0-структура;
- у SNN меньше шумовой H1-peristence.

### Гипотеза 3

TDA-метрики коррелируют с validation accuracy.

Например:

- снижение H1-энтропии связано с ростом качества;
- рост долгоживущих H0-компонент связан с лучшим обобщением;
- расстояние Wasserstein между текущей и финальной диаграммой уменьшается по мере обучения.

def sanitize_for_json(obj):
    """
    Replace NaN/Inf by None so JSON is safer to read.
    """
    if isinstance(obj, dict):
        return {k: sanitize_for_json(v) for k, v in obj.items()}
    if isinstance(obj, list):
        return [sanitize_for_json(v) for v in obj]
    if isinstance(obj, float):
        if math.isnan(obj) or math.isinf(obj):

    return obj

@dataclass
class Poset:
    name: str
    n: int
    edges: List[Tuple[int, int]]
    G: nx.DiGraph


def make_chain(n: int = 24) -> Poset:
    """
    Chain:
    0 < 1 < 2 < ... < n-1
    """
    edges = [(i, i + 1) for i in range(n - 1)]
    G = nx.DiGraph()
    G.add_nodes_from(range(n))
    G.add_edges_from(edges)
    return Poset(name="chain", n=n, edges=edges, G=G)


def make_binary_tree(depth: int = 3) -> Poset:
    """
    Binary tree with root 0.
    Edge direction: parent -> child.
    Order: parent <= child.
    """
    n = 2 ** (depth + 1) - 1
    edges = []

    for i in range(n):
        left = 2 * i + 1
        right = 2 * i + 2
        if left < n:
            edges.append((i, left))
        if right < n:
            edges.append((i, right))

    G = nx.DiGraph()
    G.add_nodes_from(range(n))
    G.add_edges_from(edges)

    return Poset(name="tree", n=n, edges=edges, G=G)


def make_grid(h: int = 5, w: int = 5) -> Poset:
    """
    Grid with product order.
    Node id = i * w + j.
    Edges:
      (i, j) -> (i+1, j)
      (i, j) -> (i, j+1)
    """
    n = h * w
    edges = []

    for i in range(h):
        for j in range(w):
            u = i * w + j
            if i + 1 < h:
                v = (i + 1) * w + j
                edges.append((u, v))
            if j + 1 < w:
                v = i * w + (j + 1)
                edges.append((u, v))

    G = nx.DiGraph()
    G.add_nodes_from(range(n))
    G.add_edges_from(edges)

    return Poset(name="grid", n=n, edges=edges, G=G)


def get_poset(name: str) -> Poset:
    if name == "chain":
        return make_chain(24)
    if name == "tree":
        return make_binary_tree(3)
    if name == "grid":
        return make_grid(5, 5)
    raise ValueError(f"Unknown poset: {name}")


def default_sources(poset: Poset) -> List[int]:
    """
    Sources for upper-set task.
    label(x) = 1 if x is in the upper set generated by sources.
    """
    if poset.name == "chain":
        # Approximately balanced suffix.
        return [poset.n // 2]

    if poset.name == "tree":
        # For depth=3, n=15.
        # Nodes 3 and 6 give disjoint small subtrees.
        if poset.n >= 15:
            return [3, 6]
        elif poset.n > 6:
            return [2, 3]
        else:
            return [1]

    if poset.name == "grid":
        # For 5x5 grid:
        # 12 = (2, 2), 16 = (3, 1)
        if poset.n >= 25:
            return [12, 16]
        else:
            return [poset.n // 2]

    return [0]


# ----------------------------
# Synthetic task
# ----------------------------

def make_task(
    poset: Poset,
    sources: List[int],
    seed: int
) -> Tuple[np.ndarray, np.ndarray, Dict[str, torch.Tensor]]:
    """
    Upper-set node classification.

    label(x) = 1 if exists s in sources such that x >= s.
    label(x) = 0 otherwise.

    Features:
      - one source-indicator feature;
      - 8 random Gaussian features.

    The source indicator makes the task learnable,
    but MLP still cannot fully solve it without structure.
    """
    positive = set()

    for s in sources:
        positive.add(s)
        positive.update(nx.descendants(poset.G, s))

    y = np.zeros(poset.n, dtype=np.int64)
    for v in positive:
        y[v] = 1

    rng = np.random.default_rng(seed)

    X_random = rng.normal(size=(poset.n, 8)).astype(np.float32)
    X_source = np.zeros((poset.n, 1), dtype=np.float32)

    for s in sources:
        X_source[s, 0] = 1.0

    X = np.concatenate([X_source, X_random], axis=1)

    idx = np.arange(poset.n)

    try:
        train_idx, temp_idx = train_test_split(
            idx,
            test_size=0.4,
            random_state=seed,
            stratify=y
        )
        val_idx, test_idx = train_test_split(
            temp_idx,
            test_size=0.5,
            random_state=seed,
            stratify=y[temp_idx]
        )
    except ValueError:
        train_idx, temp_idx = train_test_split(
            idx,
            test_size=0.4,
            random_state=seed
        )
        val_idx, test_idx = train_test_split(
            temp_idx,
            test_size=0.5,
            random_state=seed
        )

    masks = {}
    for name, arr in [("train", train_idx), ("val", val_idx), ("test", test_idx)]:
        mask = torch.zeros(poset.n, dtype=torch.bool)
        mask[arr] = True
        masks[name] = mask

    return X, y, masks

def build_gcn_adjacency(edges: List[Tuple[int, int]], n: int) -> torch.Tensor:
    """
    Symmetric normalized adjacency with self-loops:
      A_hat = D^{-1/2} (A + I) D^{-1/2}
    """
    A = np.eye(n, dtype=np.float32)

    for i, j in edges:
        A[i, j] = 1.0
        A[j, i] = 1.0

    deg = A.sum(axis=1)
    d_inv_sqrt = np.power(deg, -0.5)
    d_inv_sqrt[~np.isfinite(d_inv_sqrt)] = 0.0

    A_hat = d_inv_sqrt[:, None] * A * d_inv_sqrt[None, :]
    return torch.from_numpy(A_hat.astype(np.float32))

class MLP(nn.Module):
    def __init__(self, in_dim: int, hidden_dim: int, out_dim: int):
        super().__init__()
        self.fc1 = nn.Linear(in_dim, hidden_dim)
        self.fc2 = nn.Linear(hidden_dim, out_dim)

    def forward(self, x, *_unused):
        h = F.relu(self.fc1(x))
        logits = self.fc2(h)
        return logits, h


class GCN(nn.Module):
    """
    Very small 2-layer GCN.
    Only the first layer uses graph propagation.
    The second layer is a readout.
    """
    def __init__(self, in_dim: int, hidden_dim: int, out_dim: int):
        super().__init__()
        self.W1 = nn.Linear(in_dim, hidden_dim)
        self.W2 = nn.Linear(hidden_dim, out_dim)

    def forward(self, x, A):
        h = F.relu(torch.mm(A, self.W1(x)))
        logits = self.W2(h)
        return logits, h


class SimpleSheafNet(nn.Module):
    """
    MVP sheaf-inspired network.

    For each cover relation u -> v we define a sheaf disagreement:
        c_e = R_lower(h_u) - R_upper(h_v)

    and reduce the energy:
        E = sum_e ||c_e||^2

    The forward pass performs one gradient-like sheaf diffusion step:
        h <- h - alpha * grad_h E

    This is not the most general sheaf neural network,
    but it is enough for a first diagnostic experiment.
    """
    def __init__(
        self,
        in_dim: int,
        hidden_dim: int,
        out_dim: int,
        stalk_dim: int = 8,
        alpha: float = 0.1
    ):
        super().__init__()
        self.proj = nn.Linear(in_dim, hidden_dim)
        self.R_lower = nn.Linear(hidden_dim, stalk_dim, bias=False)
        self.R_upper = nn.Linear(hidden_dim, stalk_dim, bias=False)
        self.out = nn.Linear(hidden_dim, out_dim)
        self.alpha = float(alpha)

    def forward(self, x, edge_index):
        h = F.relu(self.proj(x))

        if edge_index.shape[1] > 0:
            lower = edge_index[0]
            upper = edge_index[1]

            z_lower = self.R_lower(h[lower])
            z_upper = self.R_upper(h[upper])

            diff = z_lower - z_upper

            # Gradient of ||diff||^2 with respect to h_lower and h_upper.
            # For z = h @ W^T, grad_h = grad_z @ W.
            msg_lower = diff @ self.R_lower.weight
            msg_upper = -diff @ self.R_upper.weight

            grad = torch.zeros_like(h)
            grad.index_add_(0, lower, msg_lower)
            grad.index_add_(0, upper, msg_upper)

            # Normalize by node degree in the Hasse diagram.
            deg = torch.zeros(h.size(0), dtype=h.dtype, device=h.device)
            deg.index_add_(
                0,
                lower,
                torch.ones(lower.size(0), dtype=h.dtype, device=h.device)
            )
            deg.index_add_(
                0,
                upper,
                torch.ones(upper.size(0), dtype=h.dtype, device=h.device)
            )
            deg = deg.clamp_min(1.0).unsqueeze(1)

            h = h - self.alpha * grad / deg

        h = F.relu(h)
        logits = self.out(h)

        return logits, h

def _clean_diagram(d: np.ndarray) -> np.ndarray:
    """
    Keep finite points with positive lifetime.
    """
    d = np.asarray(d, dtype=float)

    if d.size == 0:
        return np.empty((0, 2), dtype=float)

    if d.shape[1] > 2:
        d = d[:, :2]

    finite = d[np.isfinite(d[:, 0]) & np.isfinite(d[:, 1])]

    if finite.size == 0:
        return np.empty((0, 2), dtype=float)

    life = finite[:, 1] - finite[:, 0]
    finite = finite[life > 1e-12]

    return finite


def compute_diagrams(
    embeddings: np.ndarray,
    maxdim: int = 1,
    subsample: int = 500,
    pca_dim: int = 10,
    seed: int = 0
) -> List[np.ndarray]:
    """
    Compute persistence diagrams from embeddings.

    Pipeline:
      embeddings -> StandardScaler -> PCA -> Vietoris-Rips -> diagrams.
    """
    X = np.asarray(embeddings, dtype=np.float64)

    if X.shape[0] < 2:
        return [np.empty((0, 2), dtype=float) for _ in range(maxdim + 1)]

    if X.shape[0] > subsample:
        rng = np.random.default_rng(seed)
        idx = rng.choice(X.shape[0], size=subsample, replace=False)
        X = X[idx]

    X = StandardScaler().fit_transform(X)

    if X.shape[1] > pca_dim:
        n_components = min(pca_dim, X.shape[0], X.shape[1])
        if n_components >= 2:
            X = PCA(n_components=n_components, random_state=seed).fit_transform(X)

    # Try ripser first.
    try:
        from ripser import ripser

        result = ripser(X, maxdim=maxdim, thresh=np.inf)
        diagrams = result["dgms"]

        return [_clean_diagram(dgm) for dgm in diagrams]

    except Exception:
        # Fallback to giotto-tda.
        from gtda.homology import VietorisRipsPersistence

        homology_dimensions = list(range(maxdim + 1))

        vr = VietorisRipsPersistence(
            metric="euclidean",
            max_edge_length=np.inf,
            homology_dimensions=homology_dimensions
        )

        diagrams = vr.fit_transform(X[None, :, :])[0]

        out = []
        for dim in homology_dimensions:
            dgm = diagrams[diagrams[:, 2] == dim, :2]
            out.append(_clean_diagram(dgm))

        return out


def total_persistence(dgm: np.ndarray, p: float = 1.0) -> float:
    if len(dgm) == 0:
        return 0.0

    life = dgm[:, 1] - dgm[:, 0]
    return float(np.sum(life ** p))


def persistence_entropy(dgm: np.ndarray) -> float:
    if len(dgm) == 0:
        return 0.0

    life = dgm[:, 1] - dgm[:, 0]
    total = float(np.sum(life))

    if total <= 0.0:
        return 0.0

    probs = life / total
    probs = probs[probs > 0.0]

    return float(-np.sum(probs * np.log(probs)))


def long_lived_count(dgm: np.ndarray, rel_threshold: float = 0.1) -> int:
    if len(dgm) == 0:
        return 0

    life = dgm[:, 1] - dgm[:, 0]
    threshold = rel_threshold * float(np.max(life))

    return int(np.sum(life > threshold))


def safe_wasserstein(d1: np.ndarray, d2: np.ndarray) -> float:
    """
    Optional W1 distance.
    If persim is unavailable, returns NaN.
    """
    try:
        from persim import wasserstein
    except Exception:
        return float("nan")

    def prepare(d):
        if len(d) == 0:
            return np.array([[0.0, 0.0]], dtype=float)
        return d

    try:
        return float(wasserstein(prepare(d1), prepare(d2), matching=False))
    except Exception:
        return float("nan")


def diagram_metrics(
    diagrams: List[np.ndarray],
    first_diagrams: Optional[List[np.ndarray]] = None
) -> Dict[str, float]:
    h0 = diagrams[0] if len(diagrams) > 0 else np.empty((0, 2), dtype=float)
    h1 = diagrams[1] if len(diagrams) > 1 else np.empty((0, 2), dtype=float)

    metrics = {
        "tp_H0": total_persistence(h0, p=1.0),
        "tp_H1": total_persistence(h1, p=1.0),
        "entropy_H0": persistence_entropy(h0),
        "entropy_H1": persistence_entropy(h1),
        "long_H0": long_lived_count(h0),
        "long_H1": long_lived_count(h1),
    }

    if first_diagrams is not None:
        first_h0 = first_diagrams[0] if len(first_diagrams) > 0 else np.empty((0, 2), dtype=float)
        first_h1 = first_diagrams[1] if len(first_diagrams) > 1 else np.empty((0, 2), dtype=float)

        metrics["w1_H0_to_initial"] = safe_wasserstein(h0, first_h0)
        metrics["w1_H1_to_initial"] = safe_wasserstein(h1, first_h1)

    return metrics


# ----------------------------
# Training
# ----------------------------

def train_one(
    name: str,
    model: nn.Module,
    X: torch.Tensor,
    y: torch.Tensor,
    masks: Dict[str, torch.Tensor],
    A: torch.Tensor,
    edge_index: torch.Tensor,
    epochs: int = 200,
    lr: float = 1e-2,
    weight_decay: float = 1e-4,
    save_every: int = 10,
    tda_subsample: int = 500,
    pca_dim: int = 10,
    seed: int = 0
) -> List[Dict]:
    optimizer = torch.optim.Adam(
        model.parameters(),
        lr=lr,
        weight_decay=weight_decay
    )

    train_mask = masks["train"]
    val_mask = masks["val"]
    test_mask = masks["test"]

    history = []
    first_diagrams = None

    for epoch in range(epochs):
        model.train()
        optimizer.zero_grad()

        logits, _ = model_forward(model, name, X, A, edge_index)
        loss = F.cross_entropy(logits[train_mask], y[train_mask])

        loss.backward()
        optimizer.step()

        model.eval()
        with torch.no_grad():
            logits, hidden = model_forward(model, name, X, A, edge_index)

        pred = logits.argmax(dim=1)

        train_acc = float((pred[train_mask] == y[train_mask]).float().mean().item())
        val_acc = float((pred[val_mask] == y[val_mask]).float().mean().item())

        if epoch % save_every == 0 or epoch == epochs - 1:
            diagrams = compute_diagrams(
                hidden.cpu().numpy(),
                maxdim=1,
                subsample=tda_subsample,
                pca_dim=pca_dim,
                seed=seed
            )

            if first_diagrams is None:
                first_diagrams = diagrams

            tda = diagram_metrics(diagrams, first_diagrams)

            record = {
                "epoch": epoch,
                "loss": float(loss.item()),
                "train_acc": train_acc,
                "val_acc": val_acc,
            }
            record.update(tda)

            history.append(record)

            print(
                f"[{name}] epoch {epoch:03d} "
                f"loss={loss.item():.4f} "
                f"train_acc={train_acc:.3f} "
                f"val_acc={val_acc:.3f} "
                f"tpH0={tda['tp_H0']:.3f} "
                f"tpH1={tda['tp_H1']:.3f} "
                f"entH1={tda['entropy_H1']:.3f}"
            )

    model.eval()
    with torch.no_grad():
        logits, _ = model_forward(model, name, X, A, edge_index)

    pred = logits.argmax(dim=1)
    test_acc = float((pred[test_mask] == y[test_mask]).float().mean().item())

    if history:
        history[-1]["test_acc"] = test_acc

    return history

def plot_histories(histories: Dict[str, List[Dict]], outdir: str) -> None:
    metrics = [
        ("val_acc", "Validation accuracy"),
        ("tp_H0", "Total persistence H0"),
        ("tp_H1", "Total persistence H1"),

    fig, axes = plt.subplots(2, 2, figsize=(11, 8))

        ax.set_xlabel("epoch")
        ax.grid(alpha=0.3)
        ax.legend()

    fig.tight_layout()
    fig.savefig(os.path.join(outdir, "metrics.png"), dpi=200)

def main():

    parser.add_argument("--epochs", type=int, default=200)

    sources = default_sources(poset)

    y = torch.from_numpy(y_np).long()

        edge_index = torch.tensor(poset.edges, dtype=torch.long).t().contiguous()

    in_dim = X.shape[1]
    out_dim = int(y.max().item() + 1)

            out_dim,
            stalk_dim=args.stalk_dim,

    }

            model=model,

            edge_index=edge_index,

            lr=args.lr,
            weight_decay=args.weight_decay,
            save_every=args.save_every,

            pca_dim=10,
            seed=args.seed
        )

        histories[name] = hist

    # Save logs.

    }

        json.dump(sanitize_for_json(meta), f, indent=2)

    plot_histories(histories, args.outdir)

    print(f"\nDone. Files saved to: {args.outdir}")

## Abstract

Sheaf neural networks extend graph neural networks by incorporating sheaf-theoretic constraints that model local-to-global consistency over structured domains. ## 3. Method

### 3.1 Posets and upper-set classification

```text
Let P be a finite poset with order relation ≤. We consider node classification tasks in which labels are generated by upper sets. Given a set of source nodes S ⊂ P, the positive class is defined as

    U(S) = {x ∈ P : ∃ s ∈ S, x ≥ s}.

Nodes in U(S) receive label 1, and all other nodes receive label 0.

This task is natural for posets because the label depends directly on the order structure.
```

---

### 3.2 Models

```text
We compare three models:

1. MLP, which uses only node features.
2. GCN, which performs message passing on the undirected Hasse diagram.
3. A simplified sheaf neural network, which enforces local consistency along cover relations.
```

---

### 3.3 Simplified sheaf propagation

Для MVP можно описать так:

```text
For each cover relation e = (u, v), where u ≤ v, we define restriction maps

    ρ^L_e : R^d → R^s,
    ρ^U_e : R^d → R^s.

Given hidden node representations h_u, h_v, we define the sheaf disagreement

    c_e = ρ^L_e(h_u) - ρ^U_e(h_v).

We measure the total disagreement

    E(h) = Σ_e ||c_e||^2.

The sheaf-inspired update moves representations toward lower disagreement:

    h ← h - α ∇_h E(h).

In the MVP implementation, the restriction maps are shared linear maps for lower and upper endpoints.
```

Это честно соответствует коду.

---

### 3.4 Persistent homology pipeline

```text
At each training epoch, we extract hidden representations H_t ∈ R^{n × d}. We standardize features, optionally apply PCA, and construct a Vietoris–Rips filtration. We compute persistence diagrams for homology dimensions H0 and H1.
```

---

### 3.5 Metrics

Формулы:

### Total persistence

\[
TP_p(D) = \sum_{(b,d) \in D} (d-b)^p.
\]

В коде используется \(p=1\).

### Persistence entropy

\[
E(D) = - \sum_i p_i \log p_i,
\]

где

\[
p_i = \frac{d_i - b_i}{\sum_j (d_j - b_j)}.
\]

### Long-lived features

\[
N_{\tau}(D) = |\{(b,d) \in D : d-b > \tau\}|.
\]

В коде:

\[
\tau = 0.1 \cdot \max_i(d_i-b_i).
\]

# 11. Теоретические замечания для Магая

Это можно дать ему как заготовку.

## Замечание 1: identity sheaf и global sections

Пусть poset связный как неориентированный граф Hasse diagram.  
Пусть для всех узлов stalk один и тот же:

\[
F(x) = \mathbb{R}^d
\]

и все restriction maps:

\[
\rho_{x \le y} = \mathrm{id}.
\]

Тогда глобальная секция — это набор векторов \(s_x \in \mathbb{R}^d\), такой что для всех \(x \le y\):

\[
s_x = s_y.
\]

Если poset связный, то:

\[
H^0(P; F) \cong \mathbb{R}^d,
\]

а глобальные секции — это постоянные векторы.

Интерпретация:

> Если представления сети становятся ближе к глобальной секции, они становятся более согласованными вдоль рёбер poset. В point cloud это может выглядеть как более устойчивая H0-компонента.

---

## Замечание 2: sheaf disagreement как энергия

Для ребра \(e=(u,v)\):

\[
c_e = \rho_{u,e}(h_u) - \rho_{v,e}(h_v).
\]

Энергия:

\[
E(h) = \sum_e \|c_e\|^2.
\]

Минимизация \(E\) означает, что локальные представления лучше склеиваются.

Это можно рассматривать как:

- sheaf regularization;
- approximation of global section;
- reduction of gluing obstruction.

---

## Замечание 3: H1 и obstruction

Осторожная формулировка:

```text
Long-lived H1 features in the representation space may indicate cyclic structures or regions where local representations cannot be globally glued without residual disagreement. In sheaf-theoretic language, such phenomena are reminiscent of nontrivial first cohomology, although a rigorous equivalence requires additional assumptions.
```

Это безопасно.
